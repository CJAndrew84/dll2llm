# API lookup instructions

1. Choose a capability from [domains](README.md).
2. Search [api-index.json](search/api-index.json) for exact symbol names.
3. Verify signatures and provenance in the [API reference](api/).
4. Do not invent methods, overloads, ABI contracts or relationships.
5. Treat native exports and name correlations as discovery evidence only.
